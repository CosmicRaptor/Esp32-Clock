# Focus study artwork

Generated with the built-in ImageGen tool from the user’s two study-room references as style inspiration. The panda is the studying character; no bear appears.

- `study-panda-source.png`: original generated artwork.
- `sd/ui/focus-study-v1.jpg`: 320×240 baseline JPEG installed at `/ui/focus-study-v1.jpg` on the clock’s SD card.
- `firmware/BhoomiClock/focus_study_jpg.h`: generated byte array, used only to provision/repair the managed SD asset. UI rendering reads the SD file into PSRAM on entry and frees it on departure.

The generation prompt: warm hand-painted kawaii pastel study room, dark-brown soft outlines, peach desk, lavender evening window, hanging plants, soft star lights; one black-and-white panda in a white headband writing with a pencil in an open notebook on the left 40%; an empty warm-cream rounded panel with peach outline on the right for live native timer controls; simplified for a 320×240 LCD; no text, digits, buttons or brown bears.

Full prompt: `prompt.txt`. Regenerate the SD JPEG and provisioning header with `uv run --with pillow python tools/prepare_focus_art.py` from the repository root.
